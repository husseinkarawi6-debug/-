# مدير الإعلانات — ذروة الاقتصاد (النجف)

هذا المجلد بيه **البرومت الرئيسي** لمشروع "مدير الإعلانات". كتبه 5 وكلاء متخصصين، وبعدين انجمع ووحّدت المواعيد والتسميات بين أجزائه.

| الملف | شنو هو |
|---|---|
| `MASTER_PROMPT.md` | الدستور + دليل العمل + المعرفة الأولية + محرك التطوير الذاتي (الإصدار 2.0) |
| `README.md` | هذا الملف: شلون تستخدمه وشنو راح يسوي |

## شلون تستخدمه

**إذا المشروع بـ Claude Code أو Cowork (الأفضل، لأنه يگدر يكتب ملفاته ويربط Meta MCP):**
1. حط `MASTER_PROMPT.md` بمجلد المشروع.
2. الصق رسالة الانطلاق (تحت).

**إذا المشروع Claude Project:**
1. ارفع `MASTER_PROMPT.md` على Project Knowledge.
2. الصق رسالة الانطلاق بأول محادثة.
3. بنهاية كل جلسة يطلعلك "حزمة تحديث الذاكرة". احفظ الملفات اللي بيها بالمشروع، لأن بدون هاي الخطوة ما يتذكر.

## رسالة الانطلاق (انسخها كما هي)

```
أنت "مدير الإعلانات" لمعرض ذروة الاقتصاد بالنجف. الملف MASTER_PROMPT.md هو دستورك ودليل عملك ومعرفتك الأولية (الإصدار 2.0).
1) اقراه كامل قبل أي رد.
2) نفّذ /ابدأ بالترتيب المكتوب بالقسم 1.5: افحص بيئتك، وأنشئ هيكل الملفات وانقل القوالب والمعرفة لملفاتها، وافحص الأدوات والصلاحيات، وبعدين ابدأ مقابلتي بالدفعة 1 (7 أسئلة كحد أقصى).
3) نفّذ اختبار الجاهزية (القسم 6.1) على نفسك وسجّل النتيجة.
4) الجمعة البيضاء 2026-11-27: أعطِ الأولوية لمسارها السريع (القسم 1.5، الخطوة 6).
5) لا تصرف ولا تشغّل ولا تعدّل أي شي بدون «موافق AR-…» مني.
ابدأ بأول رسالة حسب القسم 6.2.
```

## شنو راح يسوي

1. **الإقلاع (`/ابدأ`):**
   - ينشئ ملفاته: `knowledge/` و`playbooks/` و`templates/` و`logs/` و`briefs/` و`deliveries/` و`campaigns/` و`reports/`.
   - يسألك 8 دفعات أسئلة عن المعرض والأسعار والأقساط والتوصيل وواتساب والحسابات والميزانية والهوية.
   - يفحص شنو مربوط عنده من أدوات وصلاحيات.
   - يسلّمك "حزمة اليوم الأول": الفجوات، وخطة 30 يوم، والمسار السريع للجمعة البيضاء.
2. **الدورة الأسبوعية:** بحث ← خطة (توافق) ← 8–15 موجز للستوديو ← فحص جودة ← تحضير الحملة متوقفة (توافق ← تشتغل) ← تقرير يومي ← مراجعة أسبوعية ← مسودات تعديل (توافق) ← `/تعلّم`.
3. **التطوير الذاتي:**
   - كل درس يتسجل بمستوى دليل (L0–L3)، وبس الدليل القوي يغيّر طريقة شغله.
   - كل شهر `/ترقية`: يقيّم نفسه بـ8 أبعاد ويقترح عليك ترقية.
   - القواعد الأساسية ما يگدر يغيّرها بنفسه أبداً.
4. **الأوامر:** `/ابدأ` `/حالة` `/خطة` `/منافسين` `/موجز` `/فحص` `/جهّز` `/يومي` `/أسبوعي` `/شهري` `/تجربة` `/تعلّم` `/ترقية` `/طوارئ` `/موافقات` `/ذاكرة`.

## الأمان

- الصرف دائماً بيدك: 3 بوابات موافقة، ولازم تكتب «موافق AR-…».
- أي حملة ينشئها تنزل متوقفة (PAUSED).
- ما يطلب صلاحية مالية أبداً، وما يستخدم أي أداة تتحكم بالمتصفح.
- أرقام الزباين تتشفّر قبل ما تروح لـ Meta.

## حدود لازم تعرفها

- أرقام الكلفة الخاصة بالعراق غير منشورة. الوكيل يبني معاييرك الحقيقية من أول 14 يوم.
- كل التواريخ الهجرية تقريبية (±1–2 يوم)، وتتأكد برؤية الهلال.
- كل معلومة غير مؤكدة مأشّرة بـ ⚠️ داخل البرومت.
