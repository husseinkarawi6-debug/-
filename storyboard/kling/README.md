# توليد «خيالُ الظلّ» على Kling 4.0 عبر Higgsfield API

## التشغيل
```bash
cd storyboard/kling
npm install
export HF_CREDENTIALS="KEY_ID:KEY_SECRET"   # مفتاح API من console.higgsfield.ai، لا تضعه في المستودع

npm run climax   # مشهد الذروة (الباب): 6 ثوانٍ، 720p، 9:16
npm run full     # الفيلم كامل: 30 ثانية، 720p، 9:16
# أو بإعداداتك: node generate.mjs prompts/climax_6s.txt 6 1080p
```

يطبع السكربت رابط الفيديو، وينزّله إلى `outputs/`.

## الأوامر
- `prompts/climax_6s.txt`: الذروة. الباب، وظله يبتلع ظله، واليد التي لا تطرق، والفلس المعلّق، والمشي نحو الضوء.
- `prompts/full_30s.txt`: الفيلم كامل في 10 لقطات على توقيت القصيدة. كل الأشطر فيه، والثياب تتغير مع كل مكان، والخاتمة بالكنزة العنّابية.

## ملاحظات
- هذا الـ endpoint نصّي فقط، فلا يقبل صوتاً ولا صوراً مرجعية. التزامن مع القصيدة يُضبط في المونتاج على خريطة الزمن في `../CLAUDE_CODE_PROMPT.md`.
- لا يوجد حقل للأوامر السلبية، فالممنوعات مكتوبة داخل الأمر نفسه.
- أسعار الـ API غير منشورة، وقد تختلف عن كريدت موقع Higgsfield.
- مواصفات الـ API كاملة في `KLING_4_0_API.md`.
